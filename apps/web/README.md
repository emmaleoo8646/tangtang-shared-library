# 糖糖的共享书屋 Web 站点

React + Vite 前端，数据来自 `services/api`。本地开发需先启动 PostgreSQL 和 API；Vite 会将 `/api` 代理到 `http://127.0.0.1:3000`。

```bash
npm ci
npm run dev
```

建议体验路线：用两个独立浏览器会话分别登录两个测试家庭；一方发布测试书，另一方申请；书主同意并填写公共交接地点；借方收到书后确认，归还时由书主确认收回。

刷新后数据会保留。注册向所有邮箱开放，仅需账号、邮箱、验证码和密码；成功后提醒到家庭资料完善书屋昵称和手机号码。注册需要验证邮箱，登录支持账号或已验证邮箱，忘记密码可通过邮箱重置。开发模式可在弹窗查看测试验证码；生产模式由 API 使用 SMTP 发信。封面支持裁剪上传和 AI 识别；AI 识别与简介检索依赖后端配置。

主导航为“找书、逛书屋、借阅、我的书屋”；发布入口在我的书屋内。手机与桌面共用 demo 的配色、封面比例和线条图标；发布与筛选使用支持键盘操作的选项抽屉。借阅页按“全部、进行中、已结束”查看，整批只有在每本都结束时才归入已结束。旧单本记录使用相同布局，仍通过原有单本接口处理。

`npm run check` 包含 lint、借阅摘要测试、TypeScript 检查和构建。

## 同屋多本借阅与系列

找书页和公开书屋支持直接选择单本、按书屋分组的系列卡、分册详情与批量选择。选择按当前账号保存，游客登录时合并，不在登录后自动提交。每家书屋独立提交，底部操作栏可直接申请；留言和清单复核均可选。

书屋分享地址为 `/?shop=<familyId>`。客户端通过分页 API 获取完整书目，按书屋 ID 和系列 ID 分组；搜索具体分册时直接显示该书。发布/编辑可设置所属系列与册序；我的藏书多选后可整理为系列。旧书不会自动归入系列。

借阅进展按申请聚合，支持部分审批、分次收书/归还和逐本续借/取消。借方收到实体书后开始14天借期，书主收到归还的书后结束借阅；待审批申请48小时超时。

本次本地验证使用独立的 `tt_borrow_local` 开发库和 `tt_borrow_test` 测试库（PostgreSQL 容器映射到127.0.0.1:5436），与原有演示库分开。API 示例启动命令：

```bash
cd services/api
API_HOST=127.0.0.1 PORT=3011 \
WEB_ORIGIN=http://127.0.0.1:5190,http://localhost:5190 \
AUTH_SECRET=local-batch-preview-secret-at-least-32-characters \
DATABASE_URL=postgresql://tangtang:tangtang_local_only@127.0.0.1:5436/tt_borrow_local \
npm run start:dev
```

在另一个终端启动前端：

```bash
cd apps/web
VITE_API_TARGET=http://127.0.0.1:3011 npm run dev -- --host 127.0.0.1 --port 5190 --strictPort
```

数据库应先创建并运行 `prisma migrate deploy`。上述地址、数据库凭据及密钥仅供本地开发，不用于上线。

## 头像与系列封面

家庭资料支持上传、更换、重新裁剪和移除书屋头像，点击“保存资料”后生效。头像统一采用方形圆角，并展示在个人区域、公开书屋、图书书主、选书清单及借阅双方；未上传或图片加载失败时使用昵称首字。

系列封面以图片自身比例错落叠放，完整保留内容，圆角和阴影贴合实际图片边缘。原文件已有的白边可用封面裁剪功能调整。首页“更多书屋”直接进入主导航的“逛书屋”页面。
