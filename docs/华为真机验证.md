# HarmonyOS 4.2.0 华为真机验证

状态：等待手机连接；2026-09-23 的 `adb devices -l` 未发现设备。

## 你只需完成

1. 用支持数据传输的 USB 线将华为手机连接到这台 Mac，手机保持解锁。
2. 在手机“设置”中搜索“软件版本”，连续点击“HarmonyOS 版本”7 次；返回“设置 → 系统和更新 → 开发人员选项”，开启“USB 调试”。若连接模式只有充电，可改为“传输文件”，必要时开启“仅充电模式下允许 ADB 调试”。
3. 手机上弹出“允许 USB 调试”时，确认信任这台电脑。完成后告诉 Codex“手机已连接”。

操作路径依据[华为关于 HarmonyOS 4.x USB 调试的说明](https://consumer.huawei.com/cn/support/content/zh-cn00407281/)；不同机型的文字可能略有差异。

## Codex 随后自动完成

```bash
adb devices -l
adb reverse tcp:3000 tcp:3000
adb install -r artifacts/tangtang-library-usb-debug-20260923.apk
```

先启动本地 API，再在手机上打开“糖糖的共享书屋”并点击“检查服务”，应显示“服务连接正常”。USB 版 APK 的 API 地址为 `http://127.0.0.1:3000`，通过 `adb reverse` 转发到 Mac；断开 USB 后这项连接会失效，但首页仍可打开。
